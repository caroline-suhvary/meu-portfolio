# Portfólio estático — GitHub Pages

Versão feita somente com HTML, CSS responsivo e JavaScript puro, sem bibliotecas.

## Personalização
1. Edite projetos, habilidades e certificados no início de `script.js`.
2. Coloque miniaturas e certificados na pasta `img` e informe o caminho no campo `image`.
3. Troque e-mail e links sociais em `index.html`.
4. Para mudar a foto principal, substitua `img/hero-workspace.jpg` mantendo o mesmo nome.

## Publicação
Envie `index.html`, `styles.css`, `script.js` e a pasta `img` para a raiz do repositório usado no GitHub Pages.
